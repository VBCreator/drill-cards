# Drill Cards

Тренажёр английских фраз на карточках (RU ↔ EN) для самопроверки. Интерфейс на русском.

## Устройство

- Всё приложение — один файл `index.html` (HTML + CSS + JS, без сборки и зависимостей). Открывается прямо в браузере.
- Внешние ресурсы: только шрифты Google Fonts (Onest, Literata, JetBrains Mono).
- Данные курса — массив `COURSE` в `<script>`: уроки → блоки → карточки. Карточки задаются строками `English|Русский|подсказка` через `parse(prefix, txt)`; id карточки = `<id блока>-NN`, поэтому порядок строк менять нельзя — сломается сохранённый прогресс.
- Прогресс и настройки хранятся в `localStorage` под ключом `drill-cards-v1`. Интервальное повторение упрощённое: `box` 0–5, карточка «выучена» при `box >= 3`.
- Режимы: «Изучение» (листание), «Самопроверка» (оценка 1/2/3, ошибки возвращаются в конец сессии), «Экзамен» (вперемешку, таймер на карточку, итоговый балл).
- Озвучка английского — Web Speech API (`speechSynthesis`, `en-US`).
- Тема: CSS-переменные в `:root`, тёмная тема через `prefers-color-scheme` и `data-theme`.

## Материалы

- `Drill-01.docx`, `Drill-02.docx` — исходные списки фраз для уроков #01 и #02 (в репозиторий не входят).

## Соглашения

- Сохранять однофайловую структуру и отсутствие зависимостей.
- Вёрстка рассчитана на ширину телефона (колонка до 560px).
- Новые уроки добавлять в `COURSE` с новыми уникальными id блоков.
